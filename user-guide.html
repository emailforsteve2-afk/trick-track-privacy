Trick Track user guide

SealTeam Designs · How to use the scorekeeper — not how to play Hearts or Spades · Updated October 7, 2026

What Trick Track does

Trick Track keeps score for Hearts and Spades on this device. Pick four people, choose the house rules your table uses, then enter each hand as it is played. Scores, names, history, and statistics stay on the phone.

Use the menu (☰) for Statistics, this guide, About, Privacy, or Reset App.

Start a game

Home is “What are we playing?” Tap Hearts or Spades. Unfinished games on this device appear under Resume.

History on the home screen lists finished games. Home in the header returns you there without deleting the current game.

Player names

  • On “Who is sitting?” use Add player and type a name (or email). Names are saved on this device for later games.
  • If a seat still says You, type the real name and tap Save name before you continue.
  • To rename someone, tap their name, edit it, and save.

Dealer order (seating)

Tap exactly four people in clockwise order around the table, starting with the first dealer. The “Dealer order” line shows 1 → 2 → 3 → 4 as you tap.

That tap order is the seating for the whole game. The first person you tap deals hand 1. Each later hand, the deal moves one seat clockwise.

Hearts also uses that seating for pass left / right / across (shown on each hand).

Spades: bidding starts to the left of the dealer and ends with the dealer. The bid list rotates every hand so the first bidder is on top, marked “1st to Bid.”

Spades: partners or singles

Before you pick four people, choose Partners or Four singles.

Partners: assign exactly two players to Team A and two to Team B. People sitting across from each other at a real table should be the same team.

Four singles: each person bids and scores alone.

Scoring rules

Tap Choose scoring rules. Gold chips are the selected preset. The line under the chips is a short summary. Tweaks at the bottom change the end score and a few switches.

Hearts presets: Standard (to 100), Short game (to 50), Shooter’s choice, Losing rule, Automatic −26, Omnibus (Jack of Diamonds), Required Omnibus moon, Shooting the sun, Zero out, Instant win moon.

Hearts tweaks: game ends at 50 or 100, Shooting the sun, Break-in −5. Moon and omnibus details follow the preset.

Spades presets: Standard (to 500), Short game (to 300), Blind / double nil, Harsh mercy, No mercy rule. Four singles is chosen on the previous screen.

Spades tweaks: game ends at 300 or 500, Allow nil, Blind / double nil, Mercy.

Tap Start scoring when the table agrees.

Spades: bids and tricks

  1. Bids. Tap a player (or use the highlighted row), then tap 0–13. If Allow nil is on, 0 is Nil. Blind appears when that option is on. The pad advances to the next empty seat in bid order. Table bid is the total of the four bids.
  2. When all four have a bid, tap Bids locked — enter tricks. Same player order. Enter tricks won; the four numbers must add to 13.
  3. Record hand saves scores and opens the scorecard. Bag is bags this hand; Bags is the running total. Round is points this hand; Tot is the running score. Enter next round’s bids returns you for the next deal.

Hearts: recording a hand

For each player, use + / − for hearts taken (13 hearts on the table). Tap Q on whoever took the Queen of Spades. If omnibus is on, tap J for the Jack of Diamonds. Some moon rules also ask for tricks taken.

The tally must stay consistent (hearts 13/13, Queen assigned). Record the hand to add it to the running totals. If the rules need a moon choice, the app asks +26 to others or −26 to the shooter.

History, stats, and reset

Finished games appear in History. Statistics in the menu use games stored on this device.

Reset App wipes players, history, and stats on this device. You must type Reset the app to confirm. That cannot be undone.
